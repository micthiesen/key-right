# Key Right bench guide

For the next opening, use the [one-page resistor trial guide](../off-glow/key-right-resistor-trial.pdf)
for circled F-1/J1 and F-2/J3 contacts and the firmware 0.1.4 reminder. Its
[sources and rebuild instructions](../off-glow/README.md) record the evidence
and distinguish the photographed contacts from unphotographed underside pads.

Use [C3 bench bring-up](../../bench-bring-up.md) for power, USB isolation,
chip inspection, flashing, and initial probing with the LEDs disconnected.

The [hardware record](../../hardware.md) owns the five-wire map and reported
measurements. Record performed checks in
[the validation record](../../validation-record.md). Original board photographs
and datasheets remain in [references](../../references/README.md).
